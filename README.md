# Site da Opeer

Páginas estáticas de opeer.com.br, publicadas pelo GitHub Pages a partir deste ramo.

- `/` site institucional
- `/empresas/` landing para donos e gerentes
- `/freela/` landing para freelas

O formulário de `/empresas/` envia para a função `opeer-lead` do Supabase (projeto painel-hashtag), tabela `opeer_leads`.
